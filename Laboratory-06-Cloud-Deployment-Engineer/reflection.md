# Mission 6 Reflection

## Reflection

In Mission 6, I learned how to deploy multiple containers using Docker Compose. Creating a `docker-compose.yml` file made the process easier because I could put all the necessary configurations in one place. Instead of starting each container separately, I only needed one command to run the entire application. This showed me how Infrastructure as Code helps make deployment faster and more organized.

I also realized that proper indentation is important when creating YAML files. Even a small mistake, such as using a Tab instead of spaces, can cause errors and prevent the configuration from working. Because of this, I learned to pay more attention to the format and structure of my code.

Environment variables are also important because they provide the information needed by the containers. In this activity, variables such as `MYSQL_USER`, `MYSQL_PASSWORD`, and `MYSQL_DATABASE` were used to configure the database connection. They helped Nextcloud communicate with MariaDB without needing to change the application's code.

I felt excited and satisfied when I deployed Nextcloud and accessed its setup page through the browser. It was a great experience to see how the commands I entered in the terminal could create an actual cloud storage application. Although there were several steps to follow, the activity helped me understand how the different services work together.

Since Mission 1, my knowledge of Cloud Computing has improved. I have learned more about cloud infrastructure, Docker containers, storage, and application deployment. I now understand that cloud computing involves not only using online services but also managing and connecting different components.

Overall, this mission helped me improve my technical skills and become more familiar with Docker Compose. It also taught me the importance of automation, accuracy, and proper configuration when deploying cloud applications.
