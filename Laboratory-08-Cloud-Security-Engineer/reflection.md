# Mission Reflection

Completing this activity helped me understand how a firewall protects a server. I learned that UFW controls network connections and helps block unwanted access.

I also learned that keeping unnecessary ports closed makes a server safer. In this activity, I allowed SSH and port 8080 because they were needed for server access and the web application.

Leaving MySQL port 3306 open to the public can be dangerous because attackers may try to access the database. To protect the data, database access should only be allowed for trusted users and systems.

This activity taught me that running a server is not enough. It is also important to set firewall rules correctly and check if they are working. I also learned to allow SSH before turning on the firewall to avoid losing remote access.

Adding eight laboratory missions to my GitHub portfolio shows my progress in learning cloud computing. Each activity helped me practice different skills and understand how cloud systems work.

Overall, I learned that simple security steps can help protect a server. Checking firewall settings and allowing only needed connections are important parts of cloud security.
