# Security Audit Report

## 1. Principle of Least Privilege

This means giving users and applications only the access they need. It helps keep the system safe.

## 2. Attack Surface

The attack surface includes all the ways someone might access or attack a system. Fewer open ports can help reduce security risks.

## 3. Default Deny

Default Deny blocks incoming connections unless they are allowed by a rule. This helps prevent unwanted access.
