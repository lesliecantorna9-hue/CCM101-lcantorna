Developing CloudNova as a group gave us the opportunity to apply the concepts we learned in Cloud Computing. We deployed a self-hosted cloud storage platform using Nextcloud, MariaDB, Docker, and Docker Compose in an Ubuntu VirtualBox environment.

Through this project, we experienced how different services work together to provide a functional cloud storage system. We also learned how to manage containers, configure application access, and maintain the services after deployment.

One of the challenges we encountered was configuring the Nextcloud and MariaDB containers to communicate properly. We also experienced issues when accessing Nextcloud through the browser, particularly with the trusted domain configuration.

Setting up the automated backup process was another important challenge. We needed to ensure that both the database and Nextcloud files could be backed up and stored in the correct directory.

These challenges helped us become more familiar with troubleshooting and understanding how each component of the system works.

Throughout the project, we learned how to:

- Deploy and manage applications using Docker and Docker Compose.
- Configure a database service and connect it to a web application.
- Access and manage a self-hosted cloud application.
- Create database and file backups using a Bash script.
- Schedule automated tasks using cron.
- Troubleshoot configuration and application access issues.
- Work together as a group to complete a cloud computing project.

Overall, CloudNova provided our group with valuable hands-on experience in cloud application deployment and system management. We gained a better understanding of containerization, database management, automation, and data protection.
