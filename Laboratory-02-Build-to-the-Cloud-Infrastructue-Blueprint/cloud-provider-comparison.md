## Core Infrastructure Services

| **Infrastructure Component** |     **AWS**               |        **Microsoft Azure**                   |              **Google Cloud Platform**                  |
| ------------------------------------------------------------------- | ------------------- | ------------------------- | ------------------------------- |
| *Compute*                                                           | Amazon EC2          | Azure Virtual Machines    | Google Compute Engine           |
| *Storage*                                                           | Amazon S3 + EBS     | Azure Blob Storage + Disk | Cloud Storage + Persistent Disk |
| *Networking*                                                        | VPC + Load Balancer | VNet + Load Balancer      | VPC + Cloud Load Balancing      |
| *Identity & Access (IAM)*                                           | AWS IAM             | Azure Active Directory    | Cloud IAM                       |

**3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?** Google Cloud Platform is best for AI, ML, and Kubernetes. It created Kubernetes and leads in smart technology and data tools.
