## Mission Reflection

For me, compute resources are one of the most important components because applications and services need processing power and memory to run. Without the CPU and RAM, a cloud server would not be able to process information or perform the tasks required by users and applications.

Linux supports cloud computing by providing a stable and flexible operating system for cloud servers. It can manage hardware resources, run applications, and support networking and security features. Because Linux is reliable and widely used, many cloud servers and services use it as their operating system.

Technical documentation is important because it helps engineers understand the infrastructure before making changes or deploying services. It records important information about the system, resources, configuration, and design decisions. This can help prevent mistakes and make it easier for the team to manage and troubleshoot the infrastructure.


During this laboratory activity, I learned how to use Linux commands to investigate a cloud server and identify its resources. I also learned more about compute, storage, networking, and cloud service providers. In addition, I improved my skills in writing Markdown documentation and organizing files on GitHub.

My GitHub portfolio improved because I was able to add another organized laboratory project with technical documentation and screenshots. It now shows some of the cloud computing and Linux skills that I learned during the activity. The project also demonstrates my ability to document infrastructure information and organize my work professionally.
