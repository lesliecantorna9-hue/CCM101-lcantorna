# Mission Reflection

This laboratory activity taught me how automation can make cloud management easier and faster. I learned to create a Bash script that prepares a backup folder and saves application files in a compressed archive with a timestamp. I also understood that `chmod +x` gives a script permission to execute.

Automation is helpful when handling many cloud servers because it saves time and reduces repetitive manual tasks. However, automation can also cause problems if a script contains errors or uses the wrong file path. These mistakes may affect important files or multiple servers. For this reason, scripts should be checked and tested before they are used in actual environments.

Creating a Bash script was different from writing a Docker Compose YAML file in Mission 6. Bash uses commands to perform tasks in sequence, while Docker Compose uses YAML to define application services and container settings. Both tools help simplify cloud operations, but they are used for different purposes.

From Laboratory 1 to Laboratory 9, I learned about cloud computing basics, infrastructure, services, containers, data management, deployment, security, and automation. These activities helped me understand that cloud administration also involves protecting resources, managing data, and keeping systems reliable.
