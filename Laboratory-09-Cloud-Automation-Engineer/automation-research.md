# Automation Research

## Bash Script
A Bash script is a file that contains commands executed by the Linux system in order. It helps automate tasks by running several commands without needing to type them one by one.

## Variables
Variables store information that a script can use, such as directory names and file locations. They make the script easier to update because values can be changed in one place.

## Cron Job
A Cron job schedules a command or script to run at a specific time. It is useful for automating repeated tasks, such as creating backups every day without running the script manually.
