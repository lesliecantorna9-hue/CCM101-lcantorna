# AWS Research

## Brief Overview

Amazon Web Services (AWS) is a public cloud computing platform operated by Amazon. AWS provides a large collection of cloud services for computing, storage, networking, databases, security, analytics, artificial intelligence, machine learning, and application development.

AWS was launched in 2006 and has grown into one of the world's largest cloud platforms.

## Global Infrastructure

AWS organizes its global infrastructure into geographic Regions and Availability Zones.

A Region is a separate geographic area containing multiple Availability Zones. Availability Zones are isolated locations within a Region that are designed to provide independent infrastructure and improve application availability.

AWS also provides additional infrastructure options such as Local Zones and Wavelength Zones for specialized workloads.

Organizations can deploy applications across multiple Availability Zones to improve reliability and fault tolerance.

## Cloud Management Console

The AWS Management Console is a web-based interface for managing AWS resources and services.

Users can use the console to:

- Create and manage virtual machines.
- Configure storage.
- Manage networks.
- Configure security and identity.
- Monitor cloud resources.
- Manage databases.
- Access AWS services.

The AWS Management Console provides a graphical alternative to command-line and API-based management.

## Four Core Services

### 1. Amazon EC2

Amazon Elastic Compute Cloud (EC2) provides virtual computing capacity in the AWS cloud.

EC2 can be used to run:

- Web servers
- Application servers
- Linux workloads
- Windows workloads
- Development environments
- Enterprise applications

### 2. Amazon S3

Amazon Simple Storage Service (S3) is an object-storage service.

S3 can store:

- Documents
- Images
- Videos
- Backups
- Logs
- Application data
- Website content

### 3. Amazon VPC

Amazon Virtual Private Cloud (VPC) provides networking capabilities for AWS resources.

VPC allows organizations to create logically isolated networks and configure:

- Subnets
- Routing
- Security controls
- Network connectivity
- Internet access

### 4. AWS IAM

AWS Identity and Access Management (IAM) controls access to AWS resources.

IAM allows administrators to manage:

- Users
- Groups
- Roles
- Policies
- Permissions

IAM helps organizations implement controlled and least-privilege access.

## Three Advantages

### 1. Broad Service Portfolio

AWS provides a very large selection of cloud services covering computing, storage, databases, networking, security, analytics, AI, machine learning, and application development.

### 2. Global Infrastructure

AWS has a large worldwide infrastructure that allows organizations to deploy applications in different geographic locations.

This can help organizations improve:

- Availability
- Performance
- Disaster recovery
- Geographic reach

### 3. Flexibility

AWS supports many types of architectures, including:

- Virtual machines
- Containers
- Serverless applications
- Databases
- Storage systems
- Microservices

This flexibility allows organizations to design solutions according to their specific requirements.
