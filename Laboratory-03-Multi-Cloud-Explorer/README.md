# Mission Overview

CloudNova Technologies assigned me to the Cloud Evaluation Team to investigate and compare three major public cloud platforms:

1. Amazon Web Services (AWS)
2. Microsoft Azure
3. Google Cloud Platform (GCP)

The purpose of this mission is to understand the major services offered by each cloud provider, compare their capabilities, evaluate different business requirements, and recommend the most appropriate cloud platform for different clients.

This laboratory activity also includes a Linux investigation using the KillerCoda Playground. The Linux environment will be examined using Linux commands to identify the operating system, CPU, memory, and disk space.

---

# Mission Objectives

The objectives of this laboratory activity are:

- Explore AWS, Microsoft Azure, and Google Cloud.
- Identify the core services provided by each cloud platform.
- Compare equivalent cloud services.
- Analyze different business requirements.
- Recommend appropriate cloud platforms for different clients.
- Investigate a Linux server environment using Linux commands.
- Document cloud research using Markdown.
- Organize technical information professionally.
- Continue developing the Cloud Computing GitHub Portfolio.
