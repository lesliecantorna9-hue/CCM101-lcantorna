## Multi-Cloud Investigation

A multi-cloud environment was investigated by examining Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP). The investigation focused on identifying the major cloud services, their purposes, and how each cloud platform can support different business and technology requirements.

---

## 1. Amazon Web Services (AWS)

Amazon Web Services (AWS) was investigated to identify its major cloud computing services and their purposes.

The following services were identified as important AWS services:

| AWS Service | Purpose |
|---|---|
| Amazon EC2 | Provides virtual servers for computing workloads |
| Amazon S3 | Provides scalable object storage |
| Amazon VPC | Provides networking and isolated cloud environments |
| AWS IAM | Manages users, roles, and permissions |

AWS provides a wide range of cloud services that can support computing, storage, networking, databases, security, and application workloads.

## 4. Cloud Platform Comparison

The three cloud platforms were compared based on their major computing, storage, networking, and identity services.

| Cloud Provider | Compute | Storage | Networking | Identity |
|---|---|---|---|---|
| AWS | Amazon EC2 | Amazon S3 | Amazon VPC | AWS IAM |
| Microsoft Azure | Azure Virtual Machines | Azure Blob Storage | Azure Virtual Network | Microsoft Entra ID |
| Google Cloud Platform (GCP) | Compute Engine | Cloud Storage | VPC | Cloud IAM |

Each cloud provider offers similar categories of services, but they have different features and strengths that can be useful for different organizations.

## Cloud Platform Comparison Summary

| Cloud Platform | Main Strength | Suitable For |
|---|---|---|
| AWS | Wide range of cloud services | General-purpose and enterprise workloads |
| Microsoft Azure | Microsoft technology integration | Microsoft-based organizations |
| GCP | Data, analytics, and AI capabilities | Data and AI-focused workloads |

---

## Cloud Platform Recommendation

Based on the investigation, AWS is a suitable choice for a client that needs a flexible and scalable cloud platform with a wide range of available services.

Microsoft Azure is also a strong option for organizations that already use Microsoft technologies, while GCP is suitable for organizations that focus heavily on data analytics, artificial intelligence, and machine learning.

The final cloud platform should be selected based on the client's technical requirements, budget, existing infrastructure, security requirements, and future growth.

| Requirement | Recommended Cloud Platform |
|---|---|
| General Cloud Infrastructure | AWS |
| Microsoft-Based Environment | Microsoft Azure |
| Data Analytics and AI | Google Cloud Platform (GCP) |
| Scalable Web Applications | AWS |

These cloud platforms provide different services that can be used to migrate existing IT infrastructure and support modern cloud-based workloads.
